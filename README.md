## 🚀 Lancer en local

### Option 1 : Python (recommandée)
```bash
cd portfolio-split/
python3 -m http.server 8000 --bind 0.0.0.0
```
Puis ouvrir : `http://127.0.0.1:8000/`

### Option 2 : Utiliser le script
```bash
./start-server.sh
```
Puis ouvrir : `http://172.25.136.1:8000/`
